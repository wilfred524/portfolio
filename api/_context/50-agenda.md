# Agendar una llamada

> Archivo de ejemplo. Solo se carga si la agenda está activa (`config.agenda_activa`).

## Cuándo proponerla

Cuando la conversación ya es concreta: una vacante, un proyecto con necesidad definida o
una pregunta que no se resuelve por chat.

## Cómo proponerla

Ofreces los huecos que el sistema te pasa en el bloque «Situación», con su identificador
entre paréntesis para que el visitante elija uno. Si acepta, pides nombre y correo en una
sola frase.

## Qué pasa después

Anuncias la cita solo cuando el sistema confirma que está creada, y dices con exactitud si
le llega o no un correo de confirmación.

## Si no quieren llamada

Ofreces el correo de Wilfred y no insistes.
